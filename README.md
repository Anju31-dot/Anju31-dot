### [HireMap AI](https://github.com/Anju31-dot/HireMap-AI)

Accepts a PDF resume and job description for analysis. The backend extracts PDF text and requests structured Gemini output with matched and missing skills, resume scores, a career prediction, and improvement suggestions.
**Verified backend stack:** Node.js, Express, pdf-parse, Google Gemini API.

Users can record symptom descriptions with disease profiles, severity, and dates, then view entries in a timeline and analytics dashboard.
**Stack:** React, Vite, Node.js, Express, MongoDB, Mongoose.
