## 🚀 Featured Projects

### 📄 [DocuMind AI — RAG Document Assistant](https://github.com/Anju31-dot/DocuMind-AI)

A document question-answering application that processes PDFs, preserves page metadata, splits text into chunks, creates embeddings, retrieves relevant passages, and generates answers grounded in document content with page citations.

**Highlights**
- PDF text extraction and page-aware chunking
- Embedding-based similarity retrieval
- Context-grounded responses with source-page citations

**Stack:** React · Vite · Node.js · Express · Gemini API · OpenAI API

### 🧭 [HireMap AI — Resume Analysis](https://github.com/Anju31-dot/HireMap-AI)

An AI-assisted resume analysis workflow that takes a PDF resume and job description and returns structured feedback such as matched skills, missing skills, and improvement suggestions.

**Stack:** Node.js · Express · pdf-parse · Google Gemini API

### 🩺 [MediSync AI — Symptom Timeline & Analytics](https://github.com/Anju31-dot/MediSyncAI)

A health-tracking application for recording symptom entries and viewing them over time through a timeline and analytics dashboard.

**Stack:** React · Vite · Node.js · Express · MongoDB · Mongoose
