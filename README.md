## 🚀 Selected Projects

### ✉️ [ReachInbox — Full-Stack Email Scheduler](https://github.com/Anju31-dot/ReachInbox-Full-Stack-Email-Scheduler)
A full-stack email scheduling project focused on queue-based processing and operational visibility.

- API and database-backed email records
- Redis/BullMQ delayed-job scheduling and configurable worker processing
- Sender rate-limit handling and minimum send spacing
- Queue dashboard and email status views
- PostgreSQL persistence with SMTP integration points

**Stack:** React · TypeScript · Express · PostgreSQL · Prisma · Redis · BullMQ

### 📄 [DocuMind AI — RAG Document Assistant](https://github.com/Anju31-dot/DocuMind-AI)
A document question-answering application designed to retrieve relevant passages from PDFs and ground generated responses in source content.

- PDF extraction and page-aware chunking
- Embedding-based similarity retrieval
- Context-grounded answers with source-page references

**Stack:** React · Vite · Node.js · Express · LLM APIs · Embeddings

### 🧭 [HireMap AI — Resume Analysis](https://github.com/Anju31-dot/HireMap-AI)
An AI-assisted resume analysis workflow that compares resume content with a job description and produces structured feedback.

- PDF resume processing
- Matched and missing skill identification
- Resume improvement suggestions

**Stack:** Node.js · Express · Python tooling · PDF parsing · LLM API

### 🩺 [MediSync AI — Symptom Timeline & Analytics](https://github.com/Anju31-dot/MediSyncAI)
A health-tracking application concept for recording symptom entries and reviewing them through timelines and analytics.

**Stack:** React · Vite · Node.js · Express · MongoDB
